# Download Zoop One

## Windows (Recommended)

**Direct Download**: Click the button below to download the latest Windows installer.

```
https://your-discovery-worker-url.workers.dev/download
```

Or download directly from [GitHub Releases](https://github.com/Zoop-Network/zooptray/releases).

### Installation Steps

1. Download the `.exe` installer from the link above
2. Run the installer and accept the EULA
3. Follow the installation wizard
4. A shortcut will be created on your Desktop and Start Menu
5. Ensure **WireGuard** is installed on your system:
   - Download from https://www.wireguard.com/install/
   - Or install via package manager (Windows Package Manager, Chocolatey, etc.)

## System Requirements

- **Windows 10** or later (64-bit)
- **Administrator privileges** (required for WireGuard)
- **WireGuard** installed (automatic on some systems, manual on others)
- **Internet connection**

## Troubleshooting

- If you see "WireGuard not found" errors, install WireGuard first.
- Run the application as Administrator if you encounter permission issues.
- Check `%APPDATA%\Zoop\zoop.log` for detailed logs if something goes wrong.

## Linux & macOS

For Linux and macOS builds, visit [GitHub Releases](https://github.com/Zoop-Network/zooptray/releases) and download the appropriate binary for your platform.
